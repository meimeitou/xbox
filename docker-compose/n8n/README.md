# N8N

## 简介

  N8N 是一个开源的工作流自动化工具，允许用户通过可视化界面创建和管理工作流。它支持多种集成和触发器，使得用户能够轻松地将不同的应用程序和服务连接起来，实现数据的自动流动和处理。

## TL;DR

```shell
# basic test
docker compose up -d -f docker-compose-basic.yaml
# with postgres
docker compose up -d -f docker-compose-pg.yaml
# with nginx
docker compose up -d -f docker-compose-pg-nginx.yaml
```
